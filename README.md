## Дроп с этого профиля

### Игры

| Предмет | Что делает, если подобрать |
| :--- | :--- |
| **[DungeonSeeker](https://github.com/Byrandom18/DungeonSeeker)** | Данж, хаб, инвентарь и союзник с ИИ. Behavior + Utility AI + ML-Agents. босс этой катки. |
| **[Vampiric-game](https://github.com/Byrandom18/Vampiric-game)** | Survivors-like на ECS. волны, эволюции оружия, карты. «ещё один забег и спать» — враньё. |
| **[Clicker](https://github.com/Byrandom18/Clicker)** | Кликер для Яндекс Игр. жмёшь по врагу, как по этой странице. WebGL в репо. |
| **[Tower Invasion](https://github.com/Byrandom18/Tower-Invasion)** | 2D action: удар, блок, перекат. командный рейд на 10 человек. |
